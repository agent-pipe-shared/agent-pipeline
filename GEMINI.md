# Agent-Pipeline Antigravity workspace entry

Read and follow [AGENTS.md](AGENTS.md) before working in this repository. It
is the sole workspace-instruction pointer and identifies the runtime manifest
and Operating Model as the calibrated authorities.

This adapter is intentionally thin. It does not authorize installation,
authentication, a global Antigravity configuration change, provider access,
runner certification, or a permission expansion. Use Antigravity's ordinary
interactive permission and sandbox controls; keep all non-workspace access
disabled unless the Product Owner explicitly authorizes a narrower operation.
