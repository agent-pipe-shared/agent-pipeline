# Agent-Pipeline Antigravity workspace entry

Read and follow [AGENTS.md](AGENTS.md) before working in this repository. It
is the sole workspace-instruction pointer and identifies the runtime manifest
and Operating Model as the calibrated authorities.

Nova exposes Antigravity as a **third-runner Alpha boundary**, not as a usable
AGY runtime. `node plugins/pipeline-core/scripts/antigravity-alpha-adapter.mjs
describe` returns the reviewed documentation-bound descriptor. Selection fails
closed with `AGY-ALPHA-NOT-ACTIVATED`.

The Alpha does not authorize AGY installation or discovery, authentication,
network/provider access, invocation, a global Antigravity configuration change,
runner certification, or a permission expansion. Direct AGY implementation is
tracked separately in #69 (`sprint:NONE`) until a dedicated AGY sprint is
approved.
