# PO design input — Sprint Alfred kickoff (captured 2026-08-27)

Structured extraction of the material PO input that opened the Alfred design
phase. Sanitized; no transcript. This is source evidence for the PRD/Spec;
both link back here.

## Intent

Design Sprint Alfred so the Pipeline delivers **architecture work purpose-built
for agentic software development** — producing a top result in greenfield
projects AND in existing repositories (brownfield). The design phase runs now,
ahead of Nova/Phoenix go-live, by explicit PO decision: the essential inputs
(issue set, backlog, canon) are already present on this branch.

## Constraints (stated by the PO)

1. Analyze intensively from the GitHub issues first, then the backlog items.
2. The issues and backlog items are input, **not the last word** — they were
   likely produced with less reasoning budget than this design phase has;
   the design may deviate where it can argue the deviation.
3. At least **one independent Critic round per design document** before the PO
   reviews anything.
4. External research is explicitly requested (state of the art beyond this
   repository).
5. Session economics: the design phase runs on the Design-tier model at effort
   `max` (PO-set, MP-01 named exception). When the base design work is done:
   hard stop ("Haltepunkt") so the PO can switch to the cheaper execution
   configuration — the one sanctioned MP-01 gate switch.
