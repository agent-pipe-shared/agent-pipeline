Backlog: pipeline.design-generator-repeats-large-source-material.
This is execution evidence for a prepared aggregate, not productive integration
or a release/Reader/Critic stamp.

- Canonical source commit recorded by assembly: 35d2a7d2e6c9d60bf272a9ac38db817759b8e107.
- Exact aggregate patch: da45198b2fabf5a5ab36defc1518865ca9cfde8e86a657029d865fa70de69337.
- Summary component patch: 171cc2a43b8d6065ef9075c5025f6dedcbeb4d9eaa404413e47e0a3289c35208.

  line and trailing spaces. No private session transcript was used.

  existing hash-checking C-slice loader; no canonical file or existing loader
  was written. Real Git and actual consent/capture/design-question writers
  created the private checkpoint in an owned scratch fixture.
- Actual project-onboarding-v3.mjs CLI main emitted every measured output.
  Complete output callbacks were captured locally, parsed as JSON, and saved.
  All calls returned exit 0 with zero stderr bytes. The two child processes
  returned exit 0; execution stdout/stderr and args are retained separately.
- Metadata and aggregate hashes were checked before execution, and metadata
  was checked unchanged afterwards. Input readback equals original bytes.

The input occupies **14263 bytes** once escaped as
a JSON string value without outer quotes. Raw CRLF bytes are JSON escaped, so
searching literal multiline input in serialized JSON gives zero occurrences;
the escaped string and a unique requirement sentinel both appear three times
in full output, and zero times in the summary. Full output contains
42789 bytes of escaped input copies.

--summary reduces this output by **45662 bytes
(95.50%)**, preserving
paths, target digests, target byte lengths, checkpoint binding, plan digest
and digest-bound next action. The returned fullPlanAction was executed
through CLI main, including its actual returned argv; it reproduced the
full plan object and exact stdout SHA-256
cefd2b0516bd0ddfe54a60ea6f383b86d3800d249219ddf689d676f6937ee09b.

The direct CLI default without --summary remains full content: canonical and
proposed output are byte-identical. The coordinator's prepared action adds
--summary; this measurement executes that option, but does not claim a
complete coordinator-to-host replay or output-budget acceptance.

## Remaining acceptance gaps

- The proposed summary reduces CLI response duplication. **Stored artifact
  duplication remains**: three original request copies (42090
  bytes) across design-input, PRD and Spec. Single-source section/hash references
  in derived documents are not implemented by this patch.
- Routine inspect pendingAsks compaction is not implemented by this patch
  and was not measured in this focused generator run.
- Native output tokens, host output budget, and host/display truncation are
  **unknown**. No native counter or host-budget receipt was available. Complete
  local JSON capture does not prove a Codex host response fits its output budget.
- The controlled fixture reproduces the approximate 14 KB input scale; it is
  not the greenfield user's private transcript or a claim about that historical
  run's exact token total.
