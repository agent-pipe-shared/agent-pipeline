## Concrete next decision, not yet authorized

If PO authorizes **one new attended AGY model run**, Root can execute exactly once from Main:

```text
node scratch/agent-out/r2-agy-original-critic-return-20261025/observe-native-terminal-shape-v2.mjs run
```

The command makes one `agy -p` call in a new disposable text-only repo, asks for exactly one built-in `research` child to read the fixture and return `FAIL`, uses `--sandbox`, sets a 3-minute CLI print timeout and 4-minute process timeout, and exports only a sanitized shape JSON plus a private cleanup pointer if settlement is unproven. The prompt cannot assure that the planner invokes a child. A child, if launched, may consume an additional model session; billing/resource cost is unknown. No retry or alternate prompt is included. Do not prepend the older offline test preload to this native command because its process-exit cleanup is not tied to native child settlement.

Decision use: an explicit `init` tool absence identifies a host capability gap; available tool with no PreToolUse or tool step identifies no observed attempt; PreToolUse plus typed tool error without PostToolUse identifies a refusal/error shape; a linked child terminal and PostToolUse identifies a candidate native return surface. Each still requires Source-owned binding to original prepared packet, candidate diff/tree, child identity, and held host result before any independent Critic admission. A successful parent response or the fixture's intentional `FAIL` never authorizes PASS. The AGY Source package remains partial and its original `agy-session-dispatch` suite remains interrupted; the broader integrated checks belong to Root.
