# Remaining public Scratch references preserved

The Evidence-tree audit inspected3656 tracked text artifacts.535 existing
local Scratch references already had byte-identical tracked copies.353 actual
files had no exact tracked copy at that point. This package preserves348 of
those files in338 deduplicated public objects, with source/transport hashes
and their referring evidence documents in custody.json. This includes old
captures, rejected/incremental patches and public test/launcher source.

Five exclusions are explicit:four local approval/proof-shaped JSON artifacts
and a private-plane incident report. They are not reusable authority or
required continuation inputs. Current State preserves the incident's sanitized
unknowns and prohibitions; a new runtime must create its own genuine approvals.
No private key, real authority store or local cleanup pointer is transported.

Historical logs and custody entries retain original Scratch path strings as
provenance. These are not promises that the source path exists on the next PC.
Use the tracked transport mapping. No earlier failure is promoted, missing
historical artifact reconstructed, or original proof hash silently rewritten.
Current next order remains [State](../../../../docs/state.md).
