Read [State](../../../../docs/state.md), then follow the actual AGENTS.md
re-entry and new runtime bootstrap. Read the matrix through its current pointer.
Current State is the only open/next authority; older checkpoint cancellation
or local-clone instructions are explicitly superseded.

For unfinished work, select the corresponding frozen package and use its
source→transport hash map to create a **new** inert candidate on that machine.
No original workspace path must exist. Verify actual preimages and dependencies;
do not auto-apply historical variants. Exact original capture inputs and later
configuration snapshots remain distinct. The evolving Root launcher is an
inert snapshot, not retroactive proof of every earlier run.

Real signing keys, live handles, private authority stores and unknown-live
fixture directories are intentionally nonportable. They are not source/evidence
dependencies and cannot be recreated from public proof-shaped JSON. Use the new
runtime's own genuine authority, operator route and synthetic test prerequisites.
No new stamp, native PASS, full Verify/Security or release completion is claimed.

The final validation checks each package transport's bytes and Git membership,
the current pointer/snapshot chain, active handover links and root status.
Publication still requires the new final commit's genuine push signature;
the earlier checkpoint signature subject is superseded.
