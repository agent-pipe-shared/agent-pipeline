The rigorous transfer audit exports525 public inputs:513 top-level local
briefing/spec authoring files, five required controller/G33 context inputs,
and seven exact worker manifests needed by the exported Root launcher.
Custody records original and transport hashes;446files are byte-exact and79
have explicitly sanitized local path prefixes. No earlier failed attempt,
scope prohibition or cumulative accounting is reset by this archive.

These files are inert authoring history. Many are obsolete, superseded or
prepared but never executed. **Only [current State](../../../../docs/state.md)
defines current open work and next order.** Do not dispatch old briefings or
treat model names, budgets, local receipts or past permissions in these texts
as current native authority. Regenerate a fully scoped fresh briefing from the
current State, preserved relevant inputs and current Source checks.

`custody.json` maps each original local source path to a tracked transport.
This supplies the controller/G9b full latest briefing/spec and controller's
four stripped-context dependencies, G33 recovery scope, all G8 continuation
construction inputs and finalizer/AGY original specifications. Restoring an
input means copying the selected public transport into a new inert candidate;
it never means recovering private authority or reusing live handles.
