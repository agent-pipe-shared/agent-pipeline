  - `project-calibration-identity.mjs`: the source-checkout probe stays legacy-only on purpose; its constant is now `LEGACY_CALIBRATION`, imported straight from the leaf `project-authority-read.mjs` (builtin dependencies only), because the constant is bound at module top level and a facade import could meet an import cycle at load.   - `runtime-projection-v3.mjs` (target lookup, baseline lookup, the error path label, the owned-target lookup), `project-pipeline-footprint.mjs` and `governance-scope.mjs` (baseline object key): `LEGACY_CALIBRATION` instead of the literal.

## Order established BEFORE the change (analysis E2-8)

The read order of the lists was established by reading each site, then pinned (the read-order matrix case and the existing CVCT layout cases), and every module keeps it:

- Every pair list read for this slice names the NEUTRAL file first: the in-scope sites above, and (read only, not changed) the four out-of-scope lists listed under "Not changed" (`push-threat-model-materialize`, `maintenance-delivery` and `analysis-run` loop neutral then legacy; `critic-evidence-carry` holds a Set written neutral first). No module reads the legacy file first, so a single exported list expresses every one of them; nothing in the briefing's stop condition ("a module's read order differs in a way a single resolver cannot express") applies to the LIST.
- The three READ RULES do differ, and are kept per module: `readCalibrationStakes` stops at the first file that exists; the close readback takes the first file with a string `stakes`; the artifact resolver (`resolveAuthorityArtifactPath("calibration")`) follows the MANIFEST tier. The matrix case pins the cell where they disagree (a legacy manifest, no neutral manifest, both calibration files with different `stakes`): the stakes reader says neutral, the resolver says legacy. For that reason the resolver was NOT adopted by any module here: routing the stakes readers through it would change a security reading, which the hard limits forbid. Only the constants and the shared list were adopted.
