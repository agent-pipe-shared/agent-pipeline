## What it adds

- `usage-ledger.mjs --row [label] --antigravity-transcript <file>` (exclusive mode, no transcripts root). It feeds the existing Antigravity step reader (`antigravityStepTimelineEvents`: input, output and cache-read tokens per `PLANNER_RESPONSE`) into one row under the synthetic model key `antigravity-unrecorded` and prints the MP-20 fragment: `- antigravity-unrecorded: <in> / <out> / n/a cache-write / <cache-read> -> $ unavailable (model not recorded in this transcript)`, `TOTAL: n/a (...no dollar estimate)` and a note with the number of summed steps. No price is applied, no figure is estimated, the path stays an argument and is never printed, no transcript text is printed.
- `usage-ledger.mjs --row [label] --codex-rollout <file>` (same shape, same exclusivity). It takes the last complete cumulative `total_token_usage` of the rollout (the repository's own rule, `runner-transcript-recovery.mjs` `codexUsage`; an invalid record never replaces a valid one) under the model name(s) of the `turn_context` records (only a name matching `[A-Za-z0-9._-]{1,80}` is printed, else `codex-unrecorded`) and prints `... -> n/a (price unknown)` (the existing unknown-model label: `model-prices.json` has Claude families only) and `TOTAL: n/a (no model with known price)`. The note line says that whether input includes cached tokens (and output reasoning tokens) is not measured, so the counters are printed as recorded.
- A file without a usable token record (or in another runner's layout) prints the existing empty-row sentence ("no records found for the selected session/filter.") and exits 0, so a missing row never fails a close. An unreadable file exits 1 with `antigravity-transcript-unreadable` / `codex-rollout-unreadable` plus the runnable form; a malformed or mixed argument list exits 1 with the same runnable form (no path in any message).
- The transcript reading moved into one helper `readTranscriptRecords` shared with `--timeline` (same bounds and message). The default Claude path (root, `--session`, `--latest`, `--row`, table) is not touched: the 16 existing cases are green before and after.
- `close-feature/SKILL.md` step 1 names the Antigravity and the Codex routes instead of "skip", and says to name the project directory with `--latest <projectDirName>` when the Claude root holds several (otherwise the command refuses and lists them: `resolveLatestSession`).
