## What it adds

- `lib/architecture-effective-decisions.mjs`: `classifyDeclaredAdrReferences({ rootDir, modules })` and `adrDraftHintText({ rootDir, modules, createAdrScript })`.
  - Input is the design block's module `adrReferences` (D1: that is what "expensive" means; no new field). A path `docs/adr/NNNN-<slug>.md` is identified by its slug, because the number is only a preview before binding.
  - `pending`: no `draft-<slug>.md|json` and no accepted or superseded `NNNN-<slug>` record. `skipped`: named with the reason `draft` or `accepted`. Duplicates across modules collapse; any other reference shape and a malformed module list are ignored.
  - The title is derived from the slug (D3), for example `local-cache-layer` gives `Local cache layer`. Nothing is stored; nothing is written by this module.
- `submit-plan` (`scripts/pipeline-state.mjs`, one import name plus one call region next to the cited-draft check): prints a NON-BLOCKING notice on stderr for every pending declared path. It names `create-adr.mjs --root <root> --from-design`, the one-entry `--slug <slug> --title "<Title>"` form, the REPLACE/refresh/bind steps and `cancel-submitted-plan` for an already recorded submission. Wrapped in try/catch; exit code, result shape, state and every refusal are unchanged. The text avoids the `ADR-DRAFT` refusal codes the existing pins match.
- `create-adr.mjs --from-design` (exactly `--root` and `--from-design`; any other flag with it is refused): reads the active feature's PRD design block (state `activeFeature.planPath`), classifies the declared paths and creates the pending proposals through the unchanged `createProposal`. The `REPLACE:` text stays, so `bind-adr-proposals` still refuses a draft until it is written. Idempotent: a second call creates nothing and names the skipped slugs. Nothing is written while the design approval is in force (`planApproved: true` or `planApproval.poGateAuthority`; D2: generation only before promotion); the refusal names `reopen-design`. Nothing is written while a plan submission stands either (`planSubmission` present, derived from the state field; the PRD is immutable then and a draft could not be bound); that refusal names `cancel-submitted-plan`, which `cancel-submitted-plan` clears (`planSubmission` is removed by it). Missing state, missing PRD or design block refuse with the step to take. The notice of `submit-plan` therefore names the withdraw step FIRST.
- Guard command catalogue (`lib/guard/command-catalogue.mjs`): one new closed shape for `create-adr`, exactly `--root <root>` and `--from-design`. `lib/guard/constants.mjs` needed no change.
- `skills/pipeline-start/references/happy-path.md`: one sentence naming `--from-design` before the design review.
