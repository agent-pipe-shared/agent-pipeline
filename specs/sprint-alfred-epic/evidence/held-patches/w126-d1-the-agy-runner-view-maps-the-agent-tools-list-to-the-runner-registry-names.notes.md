# w126 — D1: the Antigravity runner view maps the agent tools list to the runner's registry names

Found by the first Antigravity greenfield run (priority 1): every shipped agent definition carries Claude tool names in its frontmatter (`tools: [Read, Grep, Glob]`); the runner refused to start any pipeline subagent (`unknown component: tool "Read" not found in registry`), so no readiness review, Goldfish or Critic ever ran natively and the Elephant had to fall back to itself.

Change (`lib/agy-central-snapshot.mjs`): `transformAgyRunnerAgent` already rewrites the `model:` line of `agents/*.md` through one closed table. It now rewrites the `tools:` line through a second closed table `AGY_RUNNER_TOOL_MAP` (Read to read_file, Write to write_file, Edit to edit_file, Bash to run_command, Grep to grep_search, Glob to find_by_name). Typed refusals: `AGV-AGENT-TOOL-UNMAPPED` (a name not in the table, including an already native name), `AGV-AGENT-TOOLS-UNPARSEABLE` (not an inline bracket list), `AGV-AGENT-TOOLS-AMBIGUOUS` (two lines). An agent without a `model:` line (readiness-reviewer, consult-advisor) is now transformed for its tools instead of passing through untouched. The Claude source files are not changed; only the generated runner view differs, so the view's content identity changes.

Tests: one new case in `antigravity-global-refresh-recovers-and-installs-a-runner-view.test.mjs` (mapping, empty list, three refusals, and every shipped agent file leaves no Claude tool name in its view). That suite 36/36, `agy-central-snapshot.test.mjs` 40 pass 0 fail (41 listed, one skipped), `public-core-observation.test.mjs` 15/15. The new test was written together with the change, RED against the old transform was not run separately.

Not proven: the native names come from the runner's own registry as reported by that run; no real Antigravity run has started a subagent with the generated view yet. The mapping of any tool the agents may add later is a typed refusal, not a guess. Reinstalling the runner view is the operator's existing refresh step.
