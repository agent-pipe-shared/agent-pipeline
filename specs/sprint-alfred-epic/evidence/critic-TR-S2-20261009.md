## Findings

### F1 (major): an encoded PowerShell command can get through

The PowerShell carrier treats the first argument without a leading `-` as command text (`:504`) and stops scanning flags there. Any value-taking parameter missing from `PS_VALUE_FLAGS` (`:340-343`, `:377-380`) therefore hides a later `-enc`.

- Example: `powershell.exe -PSConsoleFile x.psc1 -enc <b64>` is admitted.
- Root cause: the outright refusal depends on the value-flag list being complete.
- Spec: §3.4 `:286` (PO decision 6), Ruling 76(a).

### F2 (major): the negative cases pass only because the test uses a fake script reader

`node --test <file>` reads and scans the file's content (`:436-440`, `:393-400`). The test file itself contains credential spellings at `ELC.test:13`, `:110` and `:246`. N2-2 and N3-1 pass only because the fake reader returns harmless text (`BENIGN_SCRIPT`).

Once wired, the classifier would refuse this slice's own recorded command and the WSL test route.

Spec: §3.4 `:330`/`:332` versus `:283`/`:315`. This needs a design decision before wiring.

### F3 (major): the secret-file list cannot hold the passive policy's name patterns

Secret names are stored as an exact-name Set (`:125`, `:202`). `passive-read-policy.mjs:10` uses patterns: `*.p12`, `*.pfx`, `*.key`, `*.pem`, `.env.*` and `id_*(.pub)`. So `openssl pkeyutl -sign -inkey scratch/copy.pem` is admitted.

Spec: §3.4 `:299`.

### F4 (major): a script passed to pwsh without `-File` is never read

pwsh's default positional parameter is `-File`. `pwsh scratch/x.ps1` runs the script, but `:504` treats `x.ps1` as command text and never reads it. CARR-18 covers only the explicit `-File` form.

Spec: §3.4 `:283`.

### F5 (minor): other scripts that a carrier executes are not read

- node's `-r`, `--require`, `--import`, `--loader` and `--experimental-loader` values are skipped (`:335-338`, `:437`).
- Only the first node file operand is read (`:440`).
- A wrapper option with a non-numeric value stops dispatch (`:410-419`), as in `sudo -u root bash x.sh` and `timeout -s KILL 5 node x.mjs`.

### F6 (minor): bash backslash escapes are not removed

The tokenizer reads every backslash as a separator (`:233`, `:297-302`). So `cat <drive>:/fixture-keyst\ore/po-keys/passphrase.txt` is admitted.

Spec: §3.4 `:288`, `:296`.

### F7 (minor): PowerShell `-Param:value` paths are not split off

The unquoted form `Get-Content -Path:<drive>:\fixture-keystore\po-keys\registry.json` is admitted (`:178`, `:182`, `:222`).

Spec: §3.4 `:289`, `:303`.

### F8 (minor): the ruled "unreadable script refuses" behaviour has no test

No test makes `readScript` return null. The code implements it at `:394-398`, but header assumption 6 still says "NOT pinned".

Spec: Ruling 76(a).
