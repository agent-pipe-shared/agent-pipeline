## Structural causes (not "agents ignore rules")

1. **Wake-up loops re-read the full context.** Stop hook / goal check-ins / task notifications each cost a full
   cached-context read for a one-line answer (~26 % together). Fix direction: the stop/goal hook decides itself
   whether anything changed (background task still running, no new PO input → stay silent / no re-invocation),
   instead of asking the Elephant.
2. **Delegation is more expensive per action than doing it inline.** A dispatch needs template filling, a record,
   guard checks; read-only helpers (`Explore`/`Plan`) are refused. So the locally cheapest step is "read it myself",
   which is globally the most expensive. Fix direction: a cheap, guard-admitted read-only research route (Sonnet) with
   a one-line briefing form; unblock `Explore`/`Plan`.
3. **Guard false positives cost retries in the expensive context** (5.4 %). Fix direction: package 4, rg grammar,
   and admitting exact passive reads (e.g. task output files).
4. **Persistence and briefing authoring happen in the Elephant** (10 %). Fix direction: generated briefings from
   structured fields; persistence of PO decisions via a small tool.

5. **Every dispatch pays a bootstrap-receipt detour** (observed SST2, QP5-PREP, NULSWEEP2, 2026-10-05): the first
   Write is refused with `GUARD-BOOTSTRAP-RECEIPT-MISSING` until the agent reads files and runs
   `pipeline-start-preflight.mjs` — 2–3 tool calls, 5–15 % of a 15–40-call budget. Fix direction (enforcement
   layer, zero agent cost): the SubagentStart hook records the receipt itself, or the template's step 0 runs the
   preflight before anything else.

6. **Critics lose ~40 % of their budget to guard denials** (Critic B, bundle review 2026-10-05: 9 of 22 calls
   refused): `DISPATCH-BUDGET-INPUT-INVALID (counter-lock-busy)` on two parallel tool calls in one message (budget
   counter lock race); `GUARD-READ-SCOPE-OUTSIDE-ROOT` for `rg` with a quoted regex containing `|` (quoted pipe parsed
   as a pipeline); `GUARD-READ-TARGET` for Glob and directory+glob Grep; `GUARD-PARSE-UNSUPPORTED` for `find` with
   several start paths and `rg` with several `-e` over several files; CR-06-D report durability impossible (Critic
   has no write tool, redirects refused, no CSPRNG primitive in the grammar). Each is an enforcement-layer defect,
   not agent misbehaviour.
