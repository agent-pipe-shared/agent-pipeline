# AGY original Critic terminal return: bounded producer gap

## Primary facts

- At base `69643e345443ca4100ab164e0db808d275b2cd78`, `plugins/pipeline-core/hooks.json` registers `PreToolUse`, `Stop`, and `PreInvocation`, with no `PostToolUse` route. `plugins/pipeline-core/hooks/antigravity-pretool-guard.mjs:818-830` calls `verifyAntigravityNativeDispatch` before `invoke_subagent`; `plugins/pipeline-core/lib/antigravity-native-dispatch-coordinator.mjs` claims the one-shot preparation artifact and returns packet/candidate JSON, with no terminal child result.
- The sanitized second-run AGY report at `specs/sprint-alfred-epic/evidence/greenfield-second-run-2026-10-25/reports/agy.md.txt:37-46` records failed Critic launch and a self-authored verdict file accepted by the finalizer. It has no original terminal child payload or transcript shape.
- Google's [Antigravity Hooks reference](https://antigravity.google/docs/hooks) documents `PostToolUse` matching and its fields: `toolCall`, `stepIdx`, optional `error`, and common `conversationId`/`transcriptPath`; it does not document a direct result body there. Google's [Antigravity CLI headless reference](https://antigravity.google/docs/cli/headless/) documents completed tool steps with `subagent_info.subagents` containing `conversation_id`, `log_uri`, `type_name`, `role`, and `workspace_uris`, and terminal structured result events. This is a potential Source readback route, not a measured guarantee for the hook transcript.

## Minimum attended experiment, if the PO selects it

1. Create one new disposable Git repository containing one innocuous text file, a base commit and a distinct candidate commit. No existing project, profile, session or credential store is opened by the experiment code. The authorized operator runs Antigravity under its normal attended account; this package itself performs no native/model call.
2. Prepare exactly one `pipeline-core:critic` native subagent with the already approved model tier, a fixed prompt asking for a short synthetic `FAIL` review of that text-only diff, and the packet/base/candidate/tree/diff bindings. Record the pretool artifact digest and host conversation ID. Launch once; do not retry after launch.
3. A narrowly registered `PostToolUse` observer for `invoke_subagent` records only whether `error` is empty, `stepIdx`, normalized call digest and the runner-supplied `conversationId`/`transcriptPath`. A bounded Source reader opens only that exact runner-supplied transcript path after the tool settles, with symlink/inode/size checks. It extracts the original child conversation ID, role, model tier, completion status and terminal result digest. It must verify the parent call digest against the consumed preparation and the child terminal digest against the same identified child; a missing field yields typed unavailable.
4. Export only a sanitized shape fixture: field names and primitive types, event order, content lengths and SHA-256 digests, parent/child ID equality flags, and the three exact validator outcomes for success, absent terminal event, and wrong child. Never export raw transcript lines, prompts, response text, absolute home paths, account IDs, tokens or keys. Delete only the experiment's exact owned files after child and reader processes settle.

The experiment's `FAIL` verdict is intentional: the first observation must prove original child custody without creating a quality-gate PASS. Only a later independently reviewed candidate can satisfy Critic PASS. Controlled synthetic event tests remain `controlled-unit-method` and cannot be promoted to native/provider assurance.

## Decision and implementation boundary

Recommended smallest route: add a `PostToolUse` `invoke_subagent` observer and Source-owned bounded original transcript reader after the experiment establishes its actual field shape. Persist consumed-preparation facts through the existing Source authority owner/registry; expose only an opaque, rechecking read handle to the finalizer. The alternative is a documented native host callback carrying original child return and identity; no such callback is evidenced by this checkout or the current Hooks contract. Until the terminal shape is measured, report `AGY-CRITIC-NATIVE-RETURN-UNAVAILABLE` and keep AGY independent PASS blocked. No new principal, key, ledger, or fallback classification is proposed.
