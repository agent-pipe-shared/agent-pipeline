## D156 facts and limit

The attended v2 run exited 0 after 22,939 ms and produced 18 sanitized events. The `init` working directory matched the expected new fixture, its tool list had 60 entries including `invoke_subagent`, and a PreToolUse hook observed one matching invocation at step 3. The stream has two updates naming `invoke_subagent` at that same step: the first state is `ACTIVE`; the second state's value is hashed as unknown by the v2 allowlist. It carries `subagent_info.subagents` as an empty array. There is no observed child ID, child terminal result, or PostToolUse hook. The parent has one `SUCCESS` result, but its response is only digested. The observation itself classifies `attempt-or-settlement-incomplete`, `nativeIndependentPass:false`, and `child-terminal-unobserved`.

Therefore the installed CLI exposed the tool and an invocation was attempted in the intended fixture. The sanitized data cannot establish whether the host rejected the invocation, the tool completed without creating a child, or another runtime path omitted the child and PostToolUse events. The hashed second state cannot honestly be called `DONE` or `ERROR`. The parent `SUCCESS` cannot stand in for an independent child result. No AGY original Critic return can be admitted from this record.
