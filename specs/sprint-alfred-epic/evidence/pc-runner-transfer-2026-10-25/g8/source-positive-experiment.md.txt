existing Codex native Critic host, bound to the same current-artifacts candidate,
source coverage, reviewer Model invocation and passing verdict. Its terminal

released Model member locator. The available controlled Model driver cannot

claim follows from the METHOD author test.

## Locator handoff needed for both active consumers

The publisher returns the approved public locator, including the original
released Model `memberRef`. Both active present-plan binding paths and signing
currently call `readAndAdmitOriginalDesignReviews` with receipt paths and bytes
only. They have no locator, so they cannot invoke `readOriginalDesignReview`
against the original registry member. The integration must persist each returned
locator in the existing design-approval binding and pass it at both call sites,
or add a Source registry lookup that resolves the exact terminal member from the
publication Source fact. Either route must reopen current Source before effects;
a receipt digest or missing fallback field alone cannot discover custody. The
current active consumer patch therefore remains separately packaged and deny
only, and must not replace Main's positive route by itself.
