## Elephant working rules (binding for every session)

- **Slicing is the Elephant's main job:** cut work into slices with disjoint write scopes so they run in parallel.
  Until worktree-per-Goldfish (R4) exists, parallel slices use the native host-commit route (Goldfish leaves changes
  uncommitted, the host hook commits the exact paths; `run_in_background: false`), proven on one slice before fan-out;
  otherwise exactly one committing agent at a time. Never two slices in one monolith.
- **Dispatch from the templates** (`templates/prompts/goldfish-task.md`, `critic-review.md`), full briefing inline in
  the prompt. Goldfish tier per agent definition; Opus Critic only for architecture/guardrail/security work (MP-07);
  a Critic re-review sees only the correction delta.
- **PO touches per candidate:** one `sign-intent` for the bundled protected package, then one line with `apply` +
  `authorize-commit` (the Elephant stages the files BEFORE handing that line over), then the install block. Until the
  R3 fix lands, the agent cannot run `apply`/`authorize-commit` itself (GUARD-GATE-STRENGTH-SHELL).
- **Full Verify only in a native Linux clone** in WSL (`git clone /mnt/d/... "$HOME/ap-verify-<tag>"`, then
  `node harness/scripts/verify.mjs --mode candidate`); never on a `/mnt/<drive>` checkout (777 modes break private
  state), never on native Windows (host crashes). Default mode `work` runs only a diff-selected subset.
- **Nothing durable only in `scratch/`:** decisions, plans, findings, measurements and PO input go into tracked,
  sanitized files in the same work step (PO rule 2026-10-05).
- **After a restart,** earlier background dispatches may still be running; treat them as alive until their
  notification arrives or they are stopped explicitly.
- **New backlog items need the ledger step:** `reconcile-backlog-ledger.mjs` (plan, then `--activate`) and
  `check-backlog-state.mjs` before the commit.
- **Full matrix in every briefing, spec and report:** Claude / Codex / Antigravity × native Windows / WSL / macOS ×
  own / consumer repository — each cell tested, untested (reason) or not applicable.
