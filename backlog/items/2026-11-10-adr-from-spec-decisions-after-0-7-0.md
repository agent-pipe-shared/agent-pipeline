# Architecture decisions made in a Spec do not become ADRs

## Description

A Spec records design decisions that a consumer project would want as ADRs. Nothing turns them into ADRs, so the reasoning stays inside one feature package.

## Decision

PO tile 2026-11-10: after 0.7.0.
