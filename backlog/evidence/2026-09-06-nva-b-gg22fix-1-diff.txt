    fix(guard-git): scope GG-22's debt check to the commit's own pathspec
    
    GG-22 read the entire shared git index (`git diff --cached`) to decide
    whether a status-flip-debt commit was admitted, so an unrelated agent's
    staged files under concurrent dispatch could block a different, correctly
    narrow, pathspec'd ledger commit -- a measured deadlock where each side's
    remediation was the other side's forbidden action.
    
    When the commit carries an explicit `--` pathspec, evaluate only those
    named paths (reusing the tokenizer already imported for GIT-03/GIT-01,
    not a second parser). A bare commit against the staged index is unchanged.
    
    AI-Assisted: true
    Dispatch: NVA-B-GG22FIX-1 (goldfish)
