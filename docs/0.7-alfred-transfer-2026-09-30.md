## Workflow defects observed while creating this checkpoint

- The installed quality-package validator rejects `.github/` and defaults to
  a child-process output buffer too small for generated architecture HTML.
  Source fixes and regression tests are in this checkpoint; any installed copy
  must be refreshed before using those fixes.
- The installed shell guard blocks the read-only materializer command because
  its argument names the committed critical-human-proof policy. A human had
  to run the materialization externally.
- Ordinary commits after approved design should not require a new PO approval.
  Protected Guard/Verify edits have their own scoped signature route; the
  additional whole-package signature was redundant and should be removed from
  the ordinary implementation path while preserving protected-path controls.
