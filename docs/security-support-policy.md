# Security support policy

This document is the public projection of the versioned support decision for
Agent Pipeline. The currently supported release line is `0.4.x`; older lines
are end-of-life unless a later, versioned policy revision explicitly says
otherwise.

For every release, the release manifest must record the policy revision,
release version, and whether it is within this window. A release outside the
window is not silently admitted as supported.

The security owner reviews the listed contact and support window at each
release. A stale contact, unsupported reporting channel, or missing required
readiness artifact is a typed readiness failure, not an informal exception.
