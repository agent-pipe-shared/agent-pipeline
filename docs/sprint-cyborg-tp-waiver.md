# Sprint-Cyborg — temporary TP-1 to TP-5 waiver

**Decision:** The Product Owner approved the temporary procedural waiver of
TP-1, TP-2, TP-3, TP-4 and TP-5 for this Sprint-Cyborg implementation work.

The waiver permits necessary changes to the protected test and gate paths. It
does not disable or weaken those checks in configuration, does not permit a
push or production release, and does not replace Verify, Security, Critic, or
the final PO gate. Each changed protected path still requires focused tests and
the final aggregate verification run.

**End condition:** This waiver ends when the Sprint-Cyborg work reaches its
final PO gate. Any later change to a protected path requires a new explicit
authorization.
